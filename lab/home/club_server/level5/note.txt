[LEVEL 5] 便條紙（塞在一堆燒錄光碟中間）

這裡是社團的照片檔案庫，archive/ 底下是 2016 到 2023 年的東西。
八年 × 四季 × 四類，你自己算算看有幾個資料夾。

最後一個 flag 就在裡面某個 flag.txt。用 cd 一層一層點會點到天亮。

正確做法：裝一個叫 tree 的工具，它會把整個目錄畫成樹狀圖。
這台機器沒裝，因為我小拿斯從來不裝任何東西，我都用手翻。（後悔）

裝法：
    sudo apt install tree

  * sudo   = 用管理員身分執行（你這個帳號有權限，會直接過）
  * apt    = Ubuntu 的套件管理員，Linux 的 App Store
  * install tree = 給我裝 tree

裝好之後：
    cd ~/club_server/level5
    tree                看樹狀圖
    tree -L 2           只看兩層（不然會刷過去）
    tree -a             連隱藏的資料夾一起看  ← 這個很關鍵
    tree | less         用 less 慢慢捲（按 q 離開）

我要老實說一件事：我把最後的資料夾名稱前面加了一個「.」。
對，就是第 2 關那招。所以你會需要 tree -a。
我知道我很煩，但這是最後一次了。

找到之後：
    cat 那個路徑/flag.txt

（進階：其實有更快的方法。裝完 tree 之後可以試試
     tree -a | grep -n flag
 或者根本不用裝 tree：
     find . -name "flag.txt"
 這兩招我大四才學會，你現在就知道了，賺到。）
