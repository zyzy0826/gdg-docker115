flag 不在這一層。往下走：
    backup/  →  old_stuff/

指令提醒：
    ls                 先看清楚有什麼再走
    cd backup          走進 backup
    cd old_stuff       再走進 old_stuff
    ls                 看看裡面有什麼
    cat flag.txt       把 flag 印出來

也可以一次到位：
    cd ~/club_server/level1/backup/old_stuff

迷路了就打 pwd，它會告訴你你在哪。
迷太遠就打 cd ~ 回家重來，家永遠在那裡。
